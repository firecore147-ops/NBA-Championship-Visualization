# NBA Championship History — Charlie Buckman

This project is based on Charlie Buckman's original NBA Championship Visualization project. It contains the Quarto `.qmd`, executed Jupyter `.ipynb`, PNG charts, a styled table in the Quarto source, and a 149-word reflection. The data cover six NBA franchises through 2024.

## Quarto render

The GitHub Actions workflow at `.github/workflows/quarto-render.yml` installs Quarto and Python dependencies on a GitHub-hosted runner, runs `quarto render Charlie_Buckman_NBA_Visualizations.qmd --to html`, verifies the HTML, and uploads a final submission ZIP as a workflow artifact.

The supplied HTML preview was generated by Jupyter; it is **not** a genuine Quarto render, and must not be submitted as such. Only the HTML produced by a successful GitHub Actions run meets this requirement.
